## 3. Lien « Analyser dans Climat → » dans le popup cellule (ObservatoryMap)

- Nouvelle fonction pure `cellCenterFromPolygon(geometry)` dans `era5-grid.ts` :
  récupère le centre exact d'un carré de grille ERA5 depuis la bounding box de
  son anneau (les carrés sont construits ±`ERA5_CELL_HALF` autour du centre
  exact, donc le midpoint de la bbox le retrouve exactement).
- Le click handler du popup (`ObservatoryMap.tsx`, effet "ERA5 weather grid")
  calcule ce centre depuis `f.geometry` (la feature cliquée) et ajoute un bloc
  `<a href="/climat?lat=<lat.toFixed(2)>&lon=<lon.toFixed(2)>">` — même
  convention de formatage que `useSelectedCellParam` dans `hooks/useClimat.ts`
  (2 décimales fixes), donc le lien ouvre directement le panneau Point pré-rempli
  sur la même cellule.
- Le lien est ajouté à toutes les branches du popup (STI, SPI, raw
  temp/precip/waterBalance) — pas de mois transmis : `ClimatPage.tsx` ne lit pas
  de paramètre `?month=` (état local uniquement), donc conformité stricte à
  l'implémentation B2 réelle plutôt qu'à la formulation "lat/lon/mois" du plan.
- Lien en ancre `<a href>` classique (pas de navigation React Router) : le
  contenu du popup MapLibre est du HTML brut injecté via `setHTML`, aucun autre
  popup du fichier n'utilise de navigation React — pattern cohérent avec
  l'existant, au prix d'un rechargement complet de page (acceptable ici).
- i18n : `observatory.era5.popupClimatLink` ajouté fr/en (flèche incluse dans la
  chaîne : "Analyser dans Climat →" / "Analyze in Climat →").
