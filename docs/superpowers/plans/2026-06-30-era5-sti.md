### Task S1: Backend — STI reference + endpoint + pure helpers (TDD)
**Files:** `api/era5_anomaly.py` (+ `tests/test_era5_anomaly.py`), `api/routers/observatory_era5.py`, `api/main.py`.

- [ ] **Pure helpers (TDD)** in `api/era5_anomaly.py`:
  - `classify_index(z)` → one of the 7 class strings using thresholds `[(-inf,-1.75,'EXTREMEMENT_BAS'),(-1.75,-1.28,'TRES_BAS'),(-1.28,-0.84,'BAS'),(-0.84,0.84,'NORMAL'),(0.84,1.28,'HAUT'),(1.28,1.75,'TRES_HAUT'),(1.75,inf,'EXTREMEMENT_HAUT')]`; `None`/NaN → 'UNKNOWN'.
  - `compute_sti(window_rows, reference, window)` — `window_rows`: `{latitude,longitude,window_mean,n_months}`; `reference`: `{latitude,longitude,mean,std,n_years}`. Join on (float lat,float lon). Drop if `window_mean is None`, `n_months<window`, reference missing, or `std<=0`. `z=(window_mean-mean)/std`; output `{latitude,longitude,sti:z,index_class:classify_index(z)}`.
  - pytest: classify boundaries (-1.75,-1.28,-0.84,0.84,1.28,1.75 land in expected classes), compute_sti basic (mean=10,std=2,obs=14→z=2→'EXTREMEMENT_HAUT'), std<=0 dropped, n_months<window dropped.
- [ ] **STI reference helper** `_era5_sti_reference(window, end_month)` in `observatory_era5.py`: for each reference year in 1991-2020, the N-month window mean ending at `end_month` per cell, then AVG + STDDEV_SAMP over years. Round coords to 0.1° (use the same approach as the existing climatology — Python merge if `::numeric` on big scans is unstable; otherwise SQL `round(...,1)`). Assign each window to its ENDING year (year-boundary handling). SQL sketch:
  ```sql
  WITH win AS (  -- per cell, per ending-year: mean temp over the N months ending at :end_month
    SELECT round(latitude::numeric,1) la, round(longitude::numeric,1) lo,
           <ending_year_expr> AS wy, AVG(temperature_2m) AS wmean
    FROM gold.era5_grid
    WHERE temperature_2m IS NOT NULL
      AND "time" >= '1991-01-01' AND "time" < '2021-01-01'
      AND EXTRACT(MONTH FROM "time")::int = ANY(:months)   -- the N ending calendar months
    GROUP BY 1,2, <ending_year_expr>
  )
  SELECT la AS latitude, lo AS longitude, AVG(wmean) AS mean, STDDEV_SAMP(wmean) AS std, COUNT(*) AS n_years
  FROM win GROUP BY la, lo
  ```
  where `:months = window_end_months(end_month, window)` and `<ending_year_expr>` maps each row to the year of the window's END (for non-wrapping windows = EXTRACT(YEAR); for wrapping, rows in months > end_month belong to the next ending year — compute via: `CASE WHEN mo > :end_month THEN year+1 ELSE year END`). Cache `obs_era5_sti_ref` keyed `{window, end_month}`, own single-flight lock, TTL 604800.
  (Verify the wrapping logic against `window_end_months`; for window=1 it's just that month.)
- [ ] **Endpoint** `GET /observatory/era5/sti?window=N&date=`: resolve month_start (latest_complete_month default), window∈{1,3,6,12}; observed window mean via the existing temp window CTE (rounded coords); `ref=_era5_sti_reference(window, month_start.month)`; `return compute_sti(rows, ref, window)`. `get_cached` keyed `{window, month}`, TTL 86400.
- [ ] **Pre-warm** in `api/main.py`: warm `_era5_sti_reference(3, <latest complete month>)` alongside the existing climatology warms (parallel `asyncio.gather`, non-blocking).
